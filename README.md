# Agreed

Final commitments from a recorded conversation. Upload a two-person project discussion and get the agreed tasks, owners, deadlines and open questions, each backed by a quote you can play.

Work in progress: built as a test task for the Codebridge Product Builder role.

## Repository

- `testset/` — test recordings: scripts, expected results (written before the product existed), audio and timelines. See [testset/README.md](testset/README.md).
- `docs/DEVLOG.md` — what was done, what failed and how outputs were checked.
