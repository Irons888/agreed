# Typography

Three faces, all self-hosted, so no requests go to a font CDN:

- **Onest** for headlines and big numbers: heavy (850) and uppercase for page and section titles, bold sentence case for card titles.
- **Geist** for text, buttons and quotes.
- **Geist Mono** for labels (`tag-label`: 11 px, uppercase, wide tracking), times and money.

Uppercase is only for headlines and labels. Card titles, quotes and running text stay in sentence case, so they read like what was said.
Big numbers use `numeral`: the display face without uppercase, so “23.2 s” keeps its lowercase unit. Times and money in text use `tabular-nums`, so digits don't jump while a timer runs.
