# Typography

Three faces, all self-hosted, so no requests go to a font CDN:

- **Onest** for headings and big numbers.
- **Geist** for text, buttons, labels and quotes.
- **Geist Mono** only for timestamps, money and counts in tables, with `tabular-nums` so digits don't jump while a timer runs.

One loud thing per screen: the home headline is the only uppercase text (`headline`). Every other heading is bold sentence case (`heading`),
labels like “Owner” or “Deadline” are plain captions, and big numbers use `numeral`, so “23.2 s” keeps its lowercase unit.
